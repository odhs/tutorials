# Computação e Rede

Quais das instruções sobre máquinas virtuais (VMs) e contêineres são verdadeiras?

- As VMs são isoladas do hardware do host, enquanto os contêineres não.
- VMs e contêineres nunca compartilham a mesma instância de sistema operacional.
- Todas as VMs compartilham a mesma instância do sistema operacional.
- VMs e contêineres são isolados do hardware do host.(certa)

Ela estende as redes locais para o Azure por meio de uma conexão privada facilitada por um provedor de conectividade.

- VPN
- ExpressRoute (certa)
- Sub-rede
- VNET

Para possibilitar a comunicação entre redes virtuais, qual configuração é necessária?

- Nenhuma, essa comunicação é nativamente liberada.
- ExpressRoute
- VPN
- Emparelhamento de rede (certa)
